# Женщина в истории Казахстана

Выставка-лонгрид в пяти залах: от сакского погребения из Урджара до выборов в Курултай 2026 года.
Каждый факт на странице стоит рядом со ссылкой на источник. Весь архив (27 источников) собран в одном файле данных.

**Живая версия:** https://claude.ai/artifact/CDt8VUwgV7Cz1BB2eMqgEc
(ссылка приватная, пока владелец не откроет к ней доступ через меню Share)

## Структура

```
src/
  page.html            каркас страницы: подключает секции по порядку
  head.html            <title>, описание, шрифты
  sections/            по файлу на секцию (00-header … 12-archive, 99-footer)
  css/
    tokens.css         цвета, шрифты, шкала размеров, ритм
    base.css           сброс, типографика, фоны залов
    components.css     шапка, ссылки на источники, чипы, графики, подсказки
    sections.css       раскладка каждой секции и адаптив
    motion.css         анимации (отключаются при prefers-reduced-motion)
  js/
    main.js            точка входа
    modules/           header, reveal, counters, burial, myths, century, tooltips, archive, parallax
  data/
    sources.json       реестр источников: автор, год, тип, ссылка
    map.json           геометрия карты (генерируется)
scripts/
  build.mjs            собирает docs/ и dist/artifact.html
  make-map.mjs         строит карту из Natural Earth (world-atlas)
docs/                  готовый статический сайт (можно раздавать через GitHub Pages)
```

## Сборка

```bash
npm install
npm run map     # только если нужно пересобрать карту
npm run build   # docs/index.html + docs/assets/*, dist/artifact.html
npm run serve   # локальный просмотр docs/ на http://localhost:4173
```

## Как добавить факт и источник

1. Добавьте запись в `src/data/sources.json` (поле `year: null`, если год публикации неизвестен: на сайте выведется «б. г.»).
2. В разметке секции поставьте `{{src:id}}` или `{{srcs:id1,id2}}` сразу под утверждением.
3. `npm run build`. Сборка прервётся, если указан несуществующий `id`.

## Публикация на GitHub Pages

Settings → Pages → Build and deployment → Deploy from a branch → ветка с проектом, папка `/docs`.

## Изображения

На сайте нет сгенерированных портретов и «исторических» лиц. Карта построена по открытым данным
Natural Earth (общественное достояние), схема погребения нарисована по описанию из источника, и об этом написано в подписи к ней.
Архивные фотографии можно добавить в `<figure class="plate">`, указав в `figcaption` источник, автора, год и лицензию.

## Проверка

Проверено в Chromium на ширине 1440, 1280, 1024, 768, 390 и 375 px: горизонтальной прокрутки нет, ошибок в консоли нет.
Проверены вкладки со стереотипами (включая стрелки на клавиатуре), фильтр архива, горизонтальная лента XX века и якорная навигация.
